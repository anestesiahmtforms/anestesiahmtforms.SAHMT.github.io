# SAHMT Web

Versao web da agenda SAHMT baseada no app Android, mantendo o visual premium e as funcoes principais:

- destaque da data atual
- busca de qualquer dia da escala
- botoes `Anterior`, `Hoje` e `Proximo`
- siglas coloridas numeradas
- faixa `Ferias da semana`
- banner `SITE SAHMT`

## Arquivos

- `index.html`
- `styles.css`
- `app.js`
- `data.js`
- `sahmt_option1.png`

## Caminho mais simples para usar no Google Sites

O Google Sites nao hospeda esse tipo de pagina HTML+JS diretamente dentro da propria pagina como um app completo. O caminho mais simples e:

1. Publicar esta pasta em uma hospedagem estatica.
2. Copiar a URL publicada.
3. Na pagina `https://sites.google.com/view/sahmt/sahmt-agenda`, usar `Incorporar` e colar a URL.

## Hospedagens estaticas que funcionam bem

- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages
